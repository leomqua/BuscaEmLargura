# Busca em Largura

Implementação do que foi pedido na atividade do PDF 7:

- grafo em lista de adjacência
- busca em largura (BFS)
- busca do menor caminho usando BFS

## Como executar

```bash
python graph.py
```

## Exemplo de saída

```text
Busca em Largura: ['A', 'B', 'C', 'D', 'E', 'F']
Menor caminho de A até F: ['A', 'B', 'D', 'F']
```
